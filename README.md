# NSE Valuation Dashboard

Personal-use dashboard for NSE and BSE equities. It fetches public market data, lets you model a discounted cash-flow valuation, and produces a printable one-page valuation report.

## Run it

1. Install Node.js 18 or newer.
2. In this folder, run `npm start`.
3. Open `http://localhost:3000`.

Enter an NSE ticker such as `TCS`, `RELIANCE`, or `INFY`; append `.BO` for a BSE ticker if needed.

Market data is provided by Yahoo Finance's public endpoints and should be verified before making decisions. The report is research support, not investment advice.
